## Problem

`MeetingUpsertEntity` held `DateTimeFrom`, `DateTimeTo`, `EnqueuedTimeUtc` as `DateTime`/`DateTime?`.
`Azure.Data.Tables` SDK requires `DateTimeOffset`. Implicit cast throws `ArgumentException` when
Newtonsoft.Json produces `DateTimeKind.Unspecified` values (no `Z` suffix in JSON).

## Root Cause (ADR-001)

CLR implicit `(DateTimeOffset)DateTime` cast throws for `DateTimeKind.Unspecified`.
Safe fix: `new DateTimeOffset(dt, TimeSpan.Zero)` — works for all three `DateTimeKind` values.
