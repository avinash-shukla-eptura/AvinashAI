# NCLCON-13233 — Device Health All Devices list returns blank on page 2

## Root Cause (Confirmed)

- `MaxVersionSegments = 5` in `Connect-Telemetry/Condeco.Connect.Telemetry/ProcessTelemetryHelper.cs` line 31
- For third-party devices with >5-segment versions, `applicationVersionForComparison = null` (line 156)
- `DBNull.Value` passed to `@ApplicationVersion` in `dbo.UpsertSpaceDetails` (line 189)
- The Report API (Connect-ReportService) pagination query has a count/fetch predicate divergence when `ApplicationVersion IS NULL`, causing 204 No Content on page 2+

## Fix Repo

- **Connect-ReportService** — `https://github.com/CondecoByEptura/Connect-ReportService.git`
