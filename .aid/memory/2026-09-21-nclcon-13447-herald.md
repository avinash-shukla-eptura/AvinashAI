## Release Announcement (for Slack/Teams/Sprint Review)

**Audience:** Product / QA

The upsertlogging service in QA (`devicehub-upsertlogging-westeurope-qa`) was throwing silent exceptions when recording meeting events. Specifically, the service failed to convert date-time values correctly when writing to Azure Table Storage, causing the events to fail and then be retried automatically. This is now fixed.

No data was lost. Affected events were retried by Event Hub and eventually processed. The fix corrects how the service stores date-time values — a code-level change with no change to data formats or API behaviour.
